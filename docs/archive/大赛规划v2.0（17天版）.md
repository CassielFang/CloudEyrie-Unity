# 关卡设计

## 关卡总览

关卡名称：**青丘·狐引**。一只被浊湮侵蚀的九尾灵狐封锁了青丘谷地，青禾与莹翳必须穿过幻象，净化灵狐，恢复灵脉流通。

关卡结构：**前奏探索区 → 灵雾教学区 → Boss战场**，线性推进，总时长15\-20分钟。

# 九尾狐Boss战详细设计

## Boss设定

|属性|说明|
|---|---|
|名称|九尾灵狐·青丘遗灵|
|体型|约为青禾的3倍高，蹲伏姿态。九条尾巴展开时占屏幕1/3宽度|
|设定|青丘谷地曾经的守护灵兽，因灵脉支流被浊湮侵蚀而发狂。本性温和，被侵蚀后用幻象封锁谷地。不是敌人，是需要解救的灵物|
|视觉|本体白色灵狐，被浊湮侵蚀后周身缠绕黑雾，九尾末端为浊黑色火焰。眼睛从金色变为浊红色。净化阶段逐渐恢复白色和金瞳（这个做不出来就算了emm）|
|Boss HP|1000点（分三阶段，每阶段约333点）|
|灵炁上限|100点（Boss战内灵泉在场地两侧，可间歇恢复）|

## Phase 1：幻影（HP 100%→70%）

**核心机制**：九尾狐制造幻象分身，需灵雾形态识别真身后，切回实体形态输出。

**情绪**：紧张·摸索——玩家在试探Boss规律

### Boss行为

|\#|技能名|描述|伤害|灵炁消耗|
|---|---|---|---|---|
|1|幻象分身|Boss分裂为3个分身（1真2假），散布场地。分身做攻击假动作但无伤害判定。真身在灵雾视野下有灵炁纹路，假身为纯黑|0|—|
|2|狐爪挥击|真身近身时触发，前爪横扫。0\.5秒前摇（爪子发光），可踏云闪躲避或格挡|20|20|
|3|尾鞭扫击|尾巴横扫地面，覆盖范围大。1秒前摇（尾巴蓄力发光），跳跃躲避|25|25|
|4|分身切换|每10秒，3个分身位置重排，真身转移。幻象闪烁过渡|0|—|

### 玩家策略

1. **灵雾识破**：切灵雾态 → 飞向3个分身观察 → 真身有灵炁纹路 → 标记真身位置

2. **实体输出**：切回实体 → 对真身轻击三连或蓄力重击 → Boss可能反击，踏云闪撤离或格挡

3. **循环**：Boss分身切换后重新识破 → 继续输出

**设计意图**：第一次让玩家体验「灵雾不是战斗形态，而是侦察/辅助形态」的核心概念。

### 阶段转场

HP降至70%时，九尾狐发出哀鸣，三只分身合为一体。黑雾爆发，场地出现浊湮区域。进入Phase 2。

## Phase 2：狂乱（HP 70%→35%）

**核心机制**：九尾狐释放浊湮领域\+召唤狐火，玩家需灵活切换实体/灵雾形态应对。

**情绪**：高压·应变——玩家在多线程压力下做形态选择

### Boss行为

|\#|技能名|描述|伤害|灵炁消耗|
|---|---|---|---|---|
|5|浊湮领域|场地出现2\-3块浊湮区域（黑墨水洼），站在上面持续扣灵炁。实体形态减速，灵雾形态不受影响|5/秒|持续|
|6|召唤狐火|Boss召唤2\-3只狐火（小型阳浊敌人），从尾部浊焰弹出。追击玩家，需实体形态击杀|15/次|15|
|7|尾焰弹幕|九条尾巴同时射出浊焰弹幕，覆盖屏幕大部分区域。1\.5秒蓄力（九尾张开发光），需灵雾态飞行穿越弹幕间隙|25/发|25|
|8|狂奔冲撞|Boss化身向玩家方向冲刺。0\.8秒前摇（后撤蓄力\+嘶吼），踏云闪侧移躲避。撞墙后2秒硬直|35|35|

### 玩家策略

|情况|推荐形态|操作|
|---|---|---|
|狐火追击|实体|轻击三连清狐火，保持移动避免被围|
|尾焰弹幕|灵雾|切灵雾飞行穿越弹幕间隙，弹幕结束后切回实体|
|浊湮区域挡路|灵雾|灵雾飞行越过，或实体踏云闪快速通过|
|狂奔冲撞|实体|踏云闪侧移，Boss撞墙硬直时输出（蓄力重击最佳窗口）|
|Boss输出窗口|实体|冲撞硬直或弹幕间隙，轻击三连或蓄力重击打满|

**灵泉机制**：场地左右两侧各有一个灵泉石台，Boss战期间可触碰恢复（30/秒，上限恢复至80%）。但灵泉恢复时Boss不会停手。

### 阶段转场

HP降至35%时，九尾狐浊湮爆发到极点，黑雾几乎覆盖整个场地。莹翳鹿角强烈发光，主动飞向青禾——触发**灵合形态强制教学**。青禾与莹翳融合，灵光爆发驱散浊湮。进入Phase 3。

## Phase 3：归心（HP 35%→0%）

**核心机制**：强制使用灵合形态，净化光环持续消耗Boss，灵炁爆发打出爆发伤害。

**情绪**：高潮·释放——从压抑到释放的情感顶点

### Boss行为

|\#|技能名|描述|伤害|灵炁消耗|
|---|---|---|---|---|
|9|浊焰爆发|九尾同时张开，向四周喷射浊焰波。灵合形态免疫浊湮伤害，可直接穿过|0（灵合免疫）|0|
|10|绝望冲撞|Boss失去理智的疯狂冲撞，频率高但轨迹可预测。灵合冲刺可规避|0（灵合免疫）|0|
|11|最后哀鸣|HP 10%时，Boss停止攻击，发出悠长哀鸣。九尾下垂，身体蜷缩。眼睛从浊红渐变回金色|0|0|

### 玩家策略

1. **灵合形态激活**：灵炁需≥50（转场前灵泉恢复确保达标），灵合消耗30点进入

2. **净化光环**：靠近Boss，净化光环持续扣HP（20/秒净化值，约2\.5秒打掉一个阶段HP段）

3. **灵炁爆发**：灵炁爆发打出大量伤害\+净化值，加速推进Boss HP下降

4. **时间窗口**：灵合形态持续约3\-4秒（灵炁从50→0），需要在窗口内打出足够伤害。如未击杀，灵合结束回到实体/灵雾，需找灵泉恢复后再次灵合

5. **最终一击**：Boss HP降至10%时哀鸣蜷缩，玩家用最后一次灵炁爆发净化收尾

**设计意图**：Phase 3 是「释放」——前两阶段玩家被Boss压迫，灵合形态反过来让玩家变成「碾压者」。灵光驱散浊湮、免疫伤害、净化光环持续输出——从被动转为主动，情感上呼应「莹翳为了保护青禾全力爆发」的叙事主题。

# 叙事设计

## 叙事原则

- **无对白**：全程不出现任何文字对话。所有故事靠画面构图、角色动作、音乐和色调传递

- **儿童友好**：不死亡、不见血。敌人是「被净化的灵体」，Boss是「被解救的灵兽」。净化后化为灵光消散

- **情感弧线**：好奇→紧张→压迫→释放→感动

- **东方留白**：不把故事说满，让评委自己感受和解读

## 叙事节点

|\#|节点|画面表现|情感|
|---|---|---|---|
|1|开场|远景山水 → 青禾和莹翳走在山道 → 前方谷地被黑雾笼罩 → 狐鸣|好奇·不安|
|2|初遇Boss|Boss从黑雾中现身，九尾展开 → 身形巨大|压迫·同情|
|3|灵合爆发|莹翳主动飞向青禾 → 二人合一 → 灵光爆发驱散黑雾 → Boss露出原本的白色灵狐形态|释放·希望|
|4|Boss哀鸣|Boss停止攻击 → 九尾下垂 → 蜷缩在地 → 悠长哀鸣 → 眼睛从浊红渐变回金色|悲悯·心痛|
|5|净化结局|最后一次灵炁爆发 → Boss被金光包裹 → 恢复白色灵狐形态 → 低头致意 → 化灵光消散 → 谷地恢复青翠 → 远处灵脉亮起|感动·释然|
