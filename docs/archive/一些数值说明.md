# 战斗系统

## 实体形态

|动作|操作|灵炁消耗|说明|
|---|---|---|---|
|轻击三连|攻击键连点|8/次|100%→120%→150%伤害递增，基础伤害为20|
|蓄力重击|按住攻击键蓄力1秒，松开释放|15|满蓄250%伤害（50）\+击退3米（目前不用），半蓄150%。Boss硬直窗口最佳输出|
|踏云闪|方向键\+闪避键|12|3米冲刺，0\.3秒无敌帧，冷却1秒|
|格挡|格挡键|10（被命中时）|正面减伤70%|
|完美格挡反制|命中前0\.2秒内格挡|0|不扣灵炁|
|二段跳|跳跃键×2|0|第二跳踏云闪，无消耗|
|移动/跳跃|方向键/跳跃键|0|基础移动|

## 灵雾形态

|动作|操作|灵炁消耗|说明|
|---|---|---|---|
|灵雾飞行|方向键|3/秒|自由飞行，无重力|
|灵弹攻击|攻击键|5/发|远程弹丸，伤害60%轻击。主要用于Phase 1识别真身后远程骚扰|
|穿越屏障|自动触发|0|灵雾态自动穿过灵界屏障|
|识破真身|靠近分身自动触发|0|灵雾视野下真身有灵炁纹路，假身为纯黑（展示已识破）|

## 灵合形态

|动作|操作|灵炁消耗|说明|
|---|---|---|---|
|灵合移动|方向键|0|悬浮移动，速度快于行走|
|净化光环|自动持续|5/秒|范围内Boss持续扣HP30/s|
|灵炁爆发|攻击键<br>|10/次<br>|AOE爆发，大量伤害\+净化值。一次50，每次灵合只能用1次|

## 形态切换

|切换|消耗|说明|
|---|---|---|
|实体→灵雾|10|按键切换|
|灵雾→实体|5|按键切换|
|灵雾→灵合|30|需灵炁≥50。Phase 3转场时自动触发|
|灵合→灵雾（自动）|0|灵炁耗尽自动切换|
