# 九尾狐Boss战修改

## Boss设定

|属性|说明|
|---|---|
|名称|九尾灵狐·青丘遗灵|
|体型|建议还是看后续舒适度进行调整|
|Boss HP|1000点（分三阶段，第一阶段300点，第二阶段350点，第3阶段350点）|
|灵炁上限|无，有攻击频率|

## Phase 1：幻影（HP 100%→70%）

**核心机制**：九尾狐制造幻象分身，需灵雾形态识别真身后，切回实体形态输出。

**情绪**：紧张·摸索——玩家在试探Boss规律

### Boss行为

|\#|技能名|描述|伤害|
|---|---|---|---|
|1|幻象分身|Boss分裂为3个分身（1真2假），散布场地，分裂分身时产生伤害|25|

要注意未识破前青禾的攻击无效，识破后方可攻击，且灵雾状态下会受到80%的伤害

### 玩家策略

1. **灵雾识破**：切灵雾态 → 飞向3个分身观察 → 标记真身位置

2. **实体输出**：切回实体 → 对真身轻击三连或蓄力重击 → Boss可能反击，踏云闪撤离或格挡

3. 可以选择灵雾远程攻击，但好像会死

**设计意图**：第一次让玩家体验「灵雾不是战斗形态，而是侦察/辅助形态」的核心概念。

### 阶段转场

HP降至70%时，九尾狐发出哀鸣，三只分身合为一体。黑雾爆发，场地出现浊湮区域。进入Phase 2。

## Phase 2：狂乱（HP 70%→35%）

**核心机制**：九尾狐释放浊湮领域\+召唤狐火，玩家需灵活切换实体/灵雾形态应对。

**情绪**：高压·应变——玩家在多线程压力下做形态选择

### Boss行为

|\#|技能名|描述|伤害|
|---|---|---|---|
|5|浊湮领域|地面上都是，除非进入灵雾或灵合状态飞起来可免疫|5/秒|
|6|召唤狐火|Boss召唤只狐火（小型阳浊敌人），从尾部浊焰弹出。追击玩家，需实体形态击杀（共6次，可用格挡挡住）|15/次|
|7|尾焰弹幕|九条尾巴同时射出浊焰弹幕，覆盖屏幕大部分区域。1\.5秒蓄力，需灵雾态飞行穿越弹幕间隙|25/发|

### 玩家策略

|情况|推荐形态|操作|
|---|---|---|
|狐火追击|实体|轻击三连清狐火，保持移动避免被围|
|尾焰弹幕|灵雾|切灵雾飞行穿越弹幕间隙，弹幕结束后切回实体|
|浊湮区域挡路|灵雾|灵雾飞行越过，或实体踏云闪快速通过|
|Boss输出窗口|实体|冲撞硬直或弹幕间隙，轻击三连或蓄力重击打满（6只狐火被杀尽后方产生伤害）|

**灵泉机制**：场地左有一个灵泉石台，Boss战期间可触碰恢复（30/秒，上限恢复至80%）。但灵泉恢复时Boss不会停手。

### 阶段转场

HP降至35%时，九尾狐浊湮爆发到极点，黑雾几乎覆盖整个场地。莹翳鹿角强烈发光，主动飞向青禾——触发**灵合形态强制教学**。青禾与莹翳融合，灵光爆发驱散浊湮。进入Phase 3。

## Phase 3：归心（HP 35%→0%）

**核心机制**：强制使用灵合形态，净化光环持续消耗Boss，灵炁爆发打出爆发伤害。

**情绪**：高潮·释放——从压抑到释放的情感顶点

### Boss行为

|\#|技能名|描述|伤害|
|---|---|---|---|
|9|浊焰爆发|九尾同时张开，向四周喷射浊焰波。灵合形态免疫浊湮伤害，可直接穿过|50/一次（灵合免疫）|

### 玩家策略

1. **灵合形态激活**：灵炁需≥50（转场前灵泉恢复确保达标），灵合消耗30点进入

2. **净化光环**：靠近Boss，净化光环持续扣HP（30/秒净化值）

3. **灵炁爆发**：灵炁爆发打出大量伤害\+净化值，加速推进Boss HP下降

4. **时间窗口**：灵合形态持续约3\-4秒（灵炁从50→0），需要在窗口内打出足够伤害。如未击杀，灵合结束回到实体/灵雾，需找灵泉恢复后再次灵合
