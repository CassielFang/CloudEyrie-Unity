# 数值唯一来源

> **本表以代码为准。** 唯一真相源是 `Assets/Resources/GameConfig.asset`
> （字段定义在 `Assets/Scripts/Core/GameConfig.cs`），本文件是它的可读快照。
>
> 二者不一致时**以 asset 为准**；本文件与 asset 不一致时，请回来更新本文件。
> 最后校对：2026-10-12（逐字段读 `GameConfig.cs` 与 `GameConfig.asset`）。

## 怎么改

- **改数值改 Inspector**（选中 `Assets/Resources/GameConfig.asset`），不要改 `GameConfig.cs` 里的默认值。
- ⚠️ **改代码里的默认值、却没重建资源 = 白改。** ScriptableObject 一旦创建，字段值就冻结在 `.asset` 里，
  之后改 `= 46.08f` 对运行时毫无影响，**且不报错**。迁移时就因这条让小怪以旧速度挪动，看起来像"小怪不会动"。
- 读取一律 `GameConfig.Current.Xxx.Yyy`（惰性），**不要缓存子配置对象**。
- 启动时 `Validate()` 会做跨字段自检，改坏关系会直接报错（见文末「不变式」）。

## 单位

**速度、距离、半径一律是「世界单位/秒」**（= 像素/秒），不是米。
Cocos 时代的"米"值乘以 `PHYSICS_2D_PTM_RATIO = 32` 得到这里的值（见 `Core/PhysicsUnits.cs`）。
所以看到 `PatrolSpeed = 46.08` 要读成"曾是 1.44 m/s"。

### 池与恢复

| 字段 | 值 | 说明 |
|---|---|---|
| `Max` | 100 | 上限 |

## 不变式（启动时 `Validate()` 自检，改坏会报错）

| # | 关系 | 破了会怎样 |
|---|---|---|
| 1 | `MergeMinSpirit ≥ SwitchMistToMerge + MergeBurstCost + ForcedMistThreshold`（30+30+10=70） | 进了灵合却放不出爆发，或爆发完当场被踢回灵雾 |
| 2 | `Initial ≤ Max` | 开局被静默夹到上限 |
| 3 | `MergeCooldown ≤ MergeMinSpirit / RegenOutOfCombat` | 冷却长过资源回复 → 变成"隐形的时间闸"，玩家只觉"有时候行有时候不行"（**警告级**） |
| 4 | `MergeSleepDuration ≤ MergeCooldown` | 门控是「或」，休眠会悄悄顶替冷却，改冷却没有效果（**警告级**） |
