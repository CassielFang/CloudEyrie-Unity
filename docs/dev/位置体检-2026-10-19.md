# 位置体检报告（2026-10-19）

> 方法：逐关把所有机关按「碰撞盒底边 − 正下方地面顶边」求差。
> `差值 > 20` 判悬空、`< -20` 判埋地。地面 = WORLD 层、非触发器、宽大于高的碰撞体
>（并排除平台/推石自身，否则每个平台都会"跟自己对上、差值为 0"）。

## 判定为「同组内不一致」的三处

同一种机关在一组里应当保持相同基准，差值却差出一大截：

| 关卡 | 对象 | 差值 | 同组其它 |
|---|---|---|---|
| 土 | `StonePillar_2` @1745 | **196** | `_1`/`_3` 都是 36 |
| 土 | `SandPillar_2` @5749 | **126** | `_1`/`_3` 都是 46 |
| 金 | `MagneticRide` @5897 | **166** | 与 `MagneticLift_*` 无地面（叠放） |

**但这一条不能直接改**：`StonePillar_2` 下方的地面顶边比其他两根低 160
（它在坑上），所以"悬空 196"也可能是地形决定的。需要实际跑图确认
「玩家从地面能不能走上去」——如果走不上去，就是摆错了。

## 其余差值都属正常

踩上去的平台本来就悬在地面上方，差值等于设计里的踏面高度：

| 关卡 | 对象 | 差值 |
|---|---|---|
| 木 | SwingPlatform_A | 166 |
| 火 | LavaStone_2 / LavaSwing / LavaStone_4 | 146 / 106 / 106 |
| 土 | StonePillar_1 / _3 | 36 / 36 |
| 土 | SandPillar_1 / _3 | 46 / 46 |
| 金 | MagneticRide | 166 |
| 水 | DriftRaft_3700 / WaterLift / Recap_Tu | 78 / 66 / 56 |

## 「无地面」（正下方没有地板）

这些都在坑/岩浆上方，符合设计（浮台就是要跨过坑）：

`Huo LavaStone_1 / LavaStone_3 / LavaStone_Sink`、
`Jin MagneticLift_4400 / MagneticLift_5000`（叠放，下面那台不算地面）、
`Shui DriftRaft_3400 / DriftRaft_4000`

## 顺带发现

- `MagneticLift_4400` 与 `MagneticLift_5000` **共用同一 x=2551**，一上一下——
  是刻意做的垂直接力，不是重叠。
- 探针本身先踩过一个坑：最初没排除 `MovingPlatform`，平台被当成地面，
  17 个平台全部"差值 0 / all ok"。**体检脚本自己也会骗人**。
