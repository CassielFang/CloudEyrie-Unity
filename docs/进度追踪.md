## 本阶段（9.23）完成的修复清单

从战斗系统落地到可稳定试玩，过程中修掉的问题——值得记录，避免重蹈：

| 问题 | 根因 |
|---|---|
| 连击永远只有第一段 | 攻击全程 0.4s 挡住输入，而连击窗口 0.3s **从起手**计时 → 结构上无法接上。改为输入缓存 + 窗口从**收招**计时 |
| 攻击"时灵时不灵" | 命中盒刚体是 **`Static`**，fixture 不跟随节点变换。改为 `Animated` + `allowSleep = false` |
| 朝左攻击打不到 | 判定盒碰撞体的 `offset` **不随朝向翻转**，朝左时判定盒留在身后。改为 offset 恒为 0，位置全由节点承担 |
| "攻击打到背后" | 立绘天然朝向判断错误（误把头发当脸）。已改用并排对照图确认 |
| 角色悬空 | 背景美术的地面线在 canvas -290，而地面碰撞体顶边在 -260 |
| 踏云闪要等到第二次起跳才生效 | 起跳当帧物理接触未断开，帧末「着地重置」把 `jumpCount` 抹掉 |
| 敌人一推就跑 | 摩擦 0.2（地面 0.8）+ 无阻尼 + 允许翻滚 |
| 控制台被灵炁日志刷屏 | `GameManager` 挂了 `spirit-energy-changed` 监听，而灵炁逐帧变化 |

> 教训：**视觉相关的判断（朝向、对齐）必须量数据或做并排对照图，不能靠肉眼扫一眼。**
> 本项目已因此栽过两次（脚底位置估错 87 单位、立绘朝向判反）。
