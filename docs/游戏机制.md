# 《云岫·狐引》当前机制详解

> **这份写的是「代码里实际生效的东西」**，不是设计意图。
> 设计文档见 `Cloud Eyrie.md` / `大赛规划v2.0（17天版）.md`；
> 两者不一致的地方，以本文为准 —— 本文的每个数字都是从代码里读出来的。
> 最后更新：2026-10-03

---

## 一、一句话

2D 横版动作。**青禾与灵伴莹翳共享一条「灵炁」**，靠三形态切换解谜与战斗；
本次雏形是一段线性关卡 + 一场三阶段九尾狐 Boss 战。

---

## 二、核心资源：灵炁

**唯一资源条。**所有动作、形态、技能都从它扣，没有血条。

| 项 | 值 | 说明 |
|---|---|---|
| 上限 | 100 | |
| 初始 | 80 | |
| 非战斗恢复 | 5 /秒 | |
| 战斗中恢复 | 1 /秒 | 「战斗中」＝场上任一敌人把自己上报为威胁源 |
| 灵泉恢复 | 30 /秒 | 上限恢复到 100%（`springRestoreCapRatio = 1`） |
| 归零 | 目前**无后果** | 设计上是「倒地回存档点」，尚未实现 |

**「战斗中」是集合而非开关**：`spiritEnergySystem.setCombatSource(this, true/false)`，
同屏多只敌人各报各的，任一只在场就算战斗中 —— 避免它们互相覆写。
（销毁敌人时**必须**退订，否则灵炁会永久停在战斗恢复档。）

## 三、三形态

青禾与莹翳共享一条灵炁，形态切换是这套玩法的核心约束。

| 形态 | 怎么进 | 消耗 | 能力 | 限制 |
|---|---|---|---|---|
| **实体** | 默认 | 每秒 0 | 走 / 二段跳 / 踏云闪 / 三连击 / 蓄力重击 / 格挡 | 灵炁 < 10 强制变灵雾 |
| **灵雾** | F | 进入 10 | 八向自由飞行、**穿过灵界屏障**、灵弹远程 | 维持 3/秒，飞行再 +2/秒；无法近战 |
| **灵合** | G（需灵炁 ≥ 50） | 进入 30 | 悬浮移动 | 冷却 20 秒；结束后莹翳**休眠 10 秒** |

其余切换：灵雾→实体 5、灵合→实体 15、灵合→灵雾 10。
**任何切换都有 0.5 秒硬直**（`switchLockDuration`）。

**灵合目前是「半成品」**：形态本身可用（能飞、能切），但设计里的
**净化光环**（20/秒）与**灵炁爆发**（30/次）**都没有实现** ——
配置项 `mergePurifyCostPerSec` / `mergeBurstCost` 存在但**无人消费**。

## 四、青禾的战斗动作

| 动作 | 键 | 灵炁 | 数值 |
|---|---|---|---|
| 轻击三连 | J 连点 | 8 /次 | 基础 15 伤害，三段倍率 **1.0 / 1.2 / 1.5**；第三段击退 1.5；连击窗口 **0.3 秒** |
| 蓄力重击 | 按住 J | 15 | 蓄力 1.0 秒；**满蓄 2.5×**、**半蓄 1.5×**；击退 3.0 |
| 踏云闪 | K | 12（**未接线**） | 3 米冲刺；**需已起跳** |
| 格挡 | 按住 L | 10（被命中时） | 正面减伤 **70%** |
| 完美格挡 | 命中前 0.2 秒内按下 | 0 | 不扣灵炁，**并反制敌人**（把它弹开 + 打入硬直） |
| 二段跳 | Space ×2 | 0 | |
| 灵弹 | 灵雾态按 J | 5 /发 | 伤害 = 轻击的 60%，速度 10，寿命 2 秒 |

⚠️ **踏云闪目前不扣灵炁**（`cloudDashCost` 配了但没接）—— `EntityForm.drainPerSecond()` 返回 0。
这是已知的待补项，不是设定。

**连击窗口从「收招」计时**，不是从起手 —— 从起手算的话窗口(0.3s) < 攻击时长(0.4s)，
连段永远接不上（这是修过的老坑）。

## 五、敌人：阳浊小怪（持弓）

一个组件 `EnemyAI` 管全部小怪，是**手写扁平状态机**（巡逻 → 发现 → 追击 → 攻击 → 死亡），
外加一层优先级更高的**受击硬直**。

**它现在是「远程弓箭手」**：攻击时真正射出箭的抛射物，而不是近身结算。

| 参数 | 值 |
|---|---|
| 巡逻速度 / 追击速度 | 1.2 / 3.2 |
| 视野 | 140（**远程型放大到 690**） |
| 攻击距离 | 72（近战）/ **460（远程）** |
| 垂直容差 | 70 —— 高差超过它就「不在同一层」，既不发现也不攻击 |
| 攻击间隔 | 1.8 秒 |
| 前摇 / 总时长 | 0.3 / 0.55（近战） ； **1.5（远程，与拉弓动画对齐）** |
| 箭 | 伤害 15、速度 900 |
| 受击硬直 | 0.3 秒（**只对带击退的命中生效**，否则轻击能把它永久锁死） |

**动画与逻辑是同步的**：小怪的攻击动画（97 帧）逐帧分析后是
「抬弓 f2-42 → 拉满保持 f43-61 → **放箭 f62** → 收势 f70-96」，
所以播 **f2→f90 并加速 2.5 倍**（约 1.5 秒），**箭在第 62 帧才生成** ——
不是各按各的计时器。走路那段则**放慢到 0.5 倍**，好和 1.2 米/秒的巡逻速度对上。

⚠️ **远程型的视野必须比射程远**（690 vs 460）。两者相等的话「看得见＝够得着」，
它会一进视野就直接开打、永远不走过来 —— 表现是「发现玩家后返回巡逻就不走路了」。

## 六、Boss：九尾狐（第一阶段「幻影」）

| 参数 | 值 |
|---|---|
| 总血量 | 1000 |
| P1 → P2 转场阈值 | 70%（＝打掉 300） |
| 分身数量 | 3（1 真 2 假） |
| 分身散布半宽 | 260 |
| 分裂伤害 | 25（半径 220，走 `receivePlayerDamage`，所以能格挡） |
| 分身重排间隔 | 10 秒 |
| 灵雾识破半径 | 260 |

**P1 的玩法循环**：

1. Boss 分裂成三身，散布在场地三处
2. **未识破前，玩家怎么打都无效**（Boss 处于免伤）
3. 玩家切**灵雾**飞近任一身 → **整组识破**：真身显青碧灵炁纹路、假身压暗
4. 切回实体输出；打到 70% → 播全屏转场动画进入 P2（**P2 尚未实现**）

**重排会作废识破**，所以要反复「识破 → 输出」。

**实现上的一处简化**：真身永远是挂 `BossP1AI` 的根节点，另两身是程序化建的诱饵
（只有立绘，没有碰撞体和血量）。重排时三者在三个位置间轮换、根节点直接移过去。
代价是**打在诱饵上的刀会穿过去、没有打击反馈**。

## 七、关卡

**《青丘·狐引》**，线性推进，横向 0 ~ 3200，出生点 x=200。

| 段 | 名称 | 从 x | 内容 |
|---|---|---|---|
| 0 | 开场过场 | — | 相机锁定，背景缓慢推移（当前仅 4 秒占位，设计是 40 秒） |
| 1 | 前奏探索 | 420 | 两只阳浊小怪 |
| 2 | 灵雾教学 | 1180 | 灵界屏障挡住去路，须切灵雾穿过并触碰机关开门 |
| 3 | 过渡段 | 1780 | 灵泉石台（靠近回灵炁） |
| 4 | Boss 战场 | 2320 | 相机锁定、背景缓慢平移，Boss 开打 |
| 5-7 | P2 / P3 / 结局 | — | **未实现** |

### 相机与背景

- **相机直接移动 `Canvas/Camera`**（不是移动世界根节点 —— 那样会和玩家刚体打架）。
  探索段跟随玩家、夹在关卡两端；Boss 战场锁定并让背景缓慢平移。
- 代价：HUD 会被推走，所以屏幕固定的东西挂 `ScreenFixed` 反向补偿。
- 背景是**卷轴式视差**：远景（系数 0.15）/ 中景（0.45）/ 散布山峰（0.62）。
  图层宽度由相机行程反推：`视口宽 + 系数 × 行程`，少给会在关卡末尾露空。

### 物理分组（重要）

玩家与小怪**彼此不阻挡**，但刀砍得到 —— 靠碰撞矩阵实现：

| 分组 | 与谁碰撞 |
|---|---|
| WORLD | 全部（地面、屏障、机关） |
| PLAYER | 只有 WORLD + ARROW |
| ENEMY | WORLD + HITBOX |
| HITBOX | 只有 ENEMY |
| ARROW | 只有 PLAYER |

**为什么不用更简单的「敌人做成 sensor」**：`AttackHitBox` 本身就是 sensor，
而 Box2D **不产生传感器与传感器之间的接触** —— 敌人也变 sensor 的话玩家就再也打不到它了。

## 八、素材与动画

美术组交的是**视频**，引擎要的是**图集序列**。三步流水线在 `art-source/_tools/`：

```bash
python gen_video_fx.py --export      # 视频 → PNG 序列（抠背景 / 接循环 / 主体等大）
python pack_atlas.py --scale 0.5     # 序列 → 图集页 + 索引 → assets/Resources/video_fx/
python extract_arrow.py              # 特例：从攻击动画里抽独立抛射物
```

播放由 `fx/SequencePlayer` 负责，**滑动窗口页缓存**（只驻留播放头附近的页）。
`MinionVisual` / `BossP1AI` 按状态驱动它播哪一段、从第几帧到第几帧。

**青禾目前是 Spine**（`青禾1`），但**只有 `idle_breath` 一条动画** ——
走路 / 跳跃 / 攻击的动作**都还没有**，正在做。
