# Noita 式升级 · 阶段小结（2026-10-30）

> 这份文档记录本轮「把《云岫》升级为 2D + 元素/机制丰富」的**实际改动与验证证据**。
> 所有结论都有可复现的数字或截图，不是"应该没问题"。
> 未完成项与需要拍板的决定放在最后一节。

## 一、元素与机关系统

### 材质表

| 材质 | 行为 |
|---|---|
| `Solid` | 实心地面 / 水+岩浆的产物（黑曜石）/ 沙+水的产物（泥） |
| `Water` | 下落、侧流；灭火；把岩浆变实心；把沙变泥 |
| `Lava` | 点燃相邻可燃物；遇水凝固 |
| `Flammable` | 可燃介质（草、油），本身不绘制 |
| `Fire` | 有寿命（40 tick），向可燃邻居蔓延，遇水熄灭 |
| `Residue` | 灰烬/蒸汽残留，只做表现 |
| `Sand` | 流沙：下落、斜滑堆积；遇水成泥；落进岩浆成渣 |

### 五境元素主线

| 境界 | 主线 | 玩家怎么用 |
|---|---|---|
| 木 Mu | 可燃藤蔓 | 火蔓延 |
| 火 Huo | 火柱 / 岩浆坑 / 油 | 岩浆遇水成石；剑气点油 |
| 土 Tu | 流沙（x≈1392） | 沙丘会塌、遇水成泥 |
| 金 Jin | 油（x≈1267）+ 剑气引火 | 站在油上挥剑点火 |
| 水 Shui | 三条水源（漂流带 / 水位） | 灭火、浇岩浆 |

### 关键实现约束（踩过的坑）

1. **火同时燃烧格数上限 260**（`maxFireCells`）。
   超过上限只禁止**蔓延与直接点燃**，不禁止已燃的烧完。
   没有这个上限时，一片 1000 格的油能把整屏糊住并把编辑器卡死。
2. **`_moved` 每 tick 清空的占位标记**。
   相邻两格沙同时判断"下方为空"会**双方都写进同一格、然后各自清空原位** ——
   一次 tick 净损失一格。实测沙丘从 2121 格掉到 740 格。
   水有同样的隐患，一并加了。
3. **贴图重画节流到 0.12 秒**（约 8Hz）。
   格子 1202×140，每帧重传整张图会把编辑器拖死。
   把 `pixelsPerCell` 从 1 提到 2 会直接卡死，已回退并写死在注释里。

## 二、新手教程（试炼场）

- 入口：标题页「启境」→ `LevelHost.PendingLevelId = "trial"` → 教完自动进木境。
- 五拍：走近木桩 → 打碎木桩 → 切灵雾 → 看火燃起 → 拾取碎片。
- 木桩：256px 程序绘制（立柱 + 稻草 + 捆绳 + 横臂），高约 200 世界单位。
- 间距：760 / 1080 / 1450 / 1900（关卡宽 2200）。
- 结束语「试炼完成 · 前往青芽境」，停留 3.5 秒再切场景。
- **修过的真 bug**：`Start()` 里抓玩家拿到 null（玩家由 bootstrap 后补），
  导致第一步"向右走"永远不满足 —— 已改成 Update 里惰性补抓。

## 三、画面层次

- 视差三层：雾 0.12 / 远山 0.35 / 近景 0.90，`drift` 全部归零（山不再自己晃）。
- 近景层：暗部亮度 16~78 → 52~104，alpha 64~235 → 28~120（原来是一条近黑横带）。
- **中景层已撤**：它是对整张 far 图做的 210 alpha 覆盖，等于一层平膜，
  把远山对比度抹平了。加它的时候只验证了"图层数=4"，没看画面，是教训。
- 色洗（ScreenGrade）+ 明暗：`GradeCanvas` 排序 -1，HUD 在 100，HUD 不会被染色。
- 光照：每关弱环境光 + 火柱/火盆/岩浆/灵泉点光。

## 四、数值与手感

| 项 | 值 | 说明 |
|---|---|---|
| 攻击 startup/active/recovery | 0.1 / 0.2 / 0.1 s | 连击窗口从**收招**起算 0.3s |
| 顿帧（命中） | 0.02 + 伤害×0.002，钳 0.03~0.11 | 轻击约 0.05，满蓄重击约 0.095 |
| 震屏（命中） | 2 + 伤害×0.12，钳 2~8 | 连续命中取较大值不叠加 |
| 受击硬直 | 0.16 s | 只锁输入，不锁物理；**格挡成功不进硬直** |
| 土狼时间 | 0.12 s | 原 0.10 |
| 跳跃缓冲 | 0.12 s | 未改 |

- `HitStop` 用 `unscaledDeltaTime` 计时，时间压到 0.02（不是 0），
  已经在顿帧时只延长不叠加，演出期间不介入。
- 元素状态可视：燃烧偏红 `(1,0.72,0.55)`、潮湿偏蓝 `(0.72,0.84,1)`。

   ### ⚠️ 远端生成这条路当前是断的（环境问题，不是决策问题）

   本会话里 `pwsh` 一直是 `spawn UNKNOWN`，**无法 SSH 到 `sjtu@192.168.200.4`**，
   因此也建不了到 ComfyUI 的隧道。

   试过绕开 shell、用 Unity 直接请求：

   ```
   UnityWebRequest.Get("http://192.168.200.4:8000/system_stats")
   → Insecure connection not allowed（Unity 默认禁 http）
   → 临时放开 PlayerSettings.insecureHttpOption 后重试
   → ConnectionError code=0 err=Request timeout
   ```

   超时说明 ComfyUI 只监听远端 `127.0.0.1:8000`，必须隧道才能访问。
   试完已把 `insecureHttpOption` **改回 NotAllowed**，没在项目里留放宽配置。

   结论：**修好 shell（或手工开隧道）之前，不要在这条路上再花时间。**

   ### ⚠️ 脚本化验证的时序坑

   `Rigidbody2D.position` 的修改要等下一次物理步才同步到 `transform.position`，
